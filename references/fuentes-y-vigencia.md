## Búsqueda mínima

Para toda norma relevante:

1. Abrir el texto oficial, no solo el resultado del buscador.
2. Registrar número, fecha, órgano emisor, publicación y última modificación visible.
3. Revisar artículos transitorios, derogaciones y versiones.
4. Buscar circulares o resoluciones complementarias en DIRECTEMAR.
5. Para decisiones locales, buscar por Capitanía, Gobernación, terminal, bahía y número del acto.
6. Para instrumentos internacionales, comprobar que Chile sea Parte del convenio y del anexo/protocolo pertinente.
7. Indicar fecha exacta de consulta.

Usar búsquedas por dominio oficial. Si una PDF no permite extracción fiable, inspeccionar sus páginas y citar el apartado visible. No atribuir al documento texto inferido de un resumen del buscador.

## Control de obligatoriedad

Clasificar cada fuente:

| Clase | Pregunta de control |
|---|---|
| Tratado | ¿Vigente para Chile y para el hecho temporal? |
| Enmienda | ¿Aceptada, promulgada, vigente y aplicable al anexo? |
| Código obligatorio | ¿Qué regla de un convenio lo vuelve obligatorio? |
| Directriz/manual | ¿Es recomendación, interpretación técnica o incorporación normativa? |
| Ley/DFL/DL | ¿Texto consolidado vigente? |
| Reglamento | ¿Potestad reglamentaria, modificaciones y norma legal habilitante? |
| Circular DGTM | ¿Vigente, destinatario, alcance material y territorial? |
| Resolución local | ¿Órgano competente, jurisdicción, instalación y vigencia? |
| Plan/instrucción interna | ¿Fue aportado legítimamente y puede usarse en este contexto? |

No deducir que una recomendación OMI es obligatoria porque sea técnicamente reconocida. No deducir que un tratado basta por sí solo para imponer una sanción administrativa.
